# PRESTOplay HLS Interstitials Demo

The [@castlabs/prestoplay SDK](https://www.npmjs.com/package/@castlabs/prestoplay)
supports HLS interstitials since version 6.19.0. See [manual page](https://demo.castlabs.com/#/docs/advertising#hls-interstitials).

## Demo App

[index.html](./index.html) contains a demo app with custom UI related
to HLS interstitials.
Start the demo app:

```sh
npm run demo
```
